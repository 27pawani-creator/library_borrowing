College Library Book Tracker

About

A SQL-based College Library Book Tracker project using SQLite to manage and analyze 15 library borrowing records, including book titles, authors, categories, student names, issue dates, due dates, return statuses, and library fines.

Objectives

- Create and manage a structured library borrowing database.
- Track books borrowed by students.
- Analyze book categories and authors.
- Identify returned and unreturned books.
- Find records based on student names and fine amounts.
- Calculate total borrowing records and library fines.
- Practice SQL queries for data retrieval and analysis.

Technologies Used

- Database: SQLite
- Language: SQL
- Platform: Online SQLite Editor
- Version Control: GitHub

SQL Concepts Used

- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- AND, OR, IN
- ORDER BY
- LIMIT
- COUNT(), SUM()
- PRAGMA

 Project Structure

- `Input/` — Sample library borrowing data
- `Queries/` — SQL queries for all 15 questions
- `Images/` — Screenshots of query outputs
- `README.md` — Project documentation
- `LICENSE` — MIT License



 Expected Results

- Total borrowing records: 15
- Unreturned books: 7
- Total fines: ₹208
- Total fines for unreturned books: ₹167

## Conclusion

This project demonstrates how SQL and SQLite can be used to store, retrieve, and analyze library borrowing records. It helps develop practical skills in database management and SQL query writing.
